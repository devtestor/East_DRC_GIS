# Phase 3 Implementation Notes

## Outcome

Start the parties, interests, and protected legal-evidence foundation without treating claims as official registered title.

## Implemented Slice

- `parties.parties` stores protected party records for individuals, organizations, government institutions, estates, and cooperatives.
- Party records include verification status and data-confidence classification.
- `rights.ownership_interests` stores parcel-linked claimed interests with interest type, claim status, optional share percentage, data confidence, and source.
- Staff-only party API supports create, read, and protected search.
- Staff-only parcel interest API supports creating and listing parcel interest/claim records.
- Staff console supports creating/searching parties and recording parcel interest claims.
- Ownership/right claims can be moved into evidence-linked human review through workflow tasks assigned to `LAND_TITLE_OFFICER`.
- Approval of an ownership-interest review marks the operational interest record `VERIFIED`; rejection marks it `REJECTED`.
- Parcel restrictions/cautions can be recorded as protected legal-evidence records.
- Active restrictions with `blocks_ownership_changes` prevent ownership-interest creation and status changes at API and database-trigger level.
- Restriction release is a separate evidence-linked workflow assigned to a scoped `LAND_TITLE_OFFICER`; approval records release actor/time and changes the restriction to `RELEASED`.
- Ownership conflict detection reports competing active ownership claims and share over-allocation as review leads; it never automatically resolves a claim or determines legal title.
- Dispute cases can link protected, versioned document metadata with relationship and audit context; document access is checked before linking or listing.
- Dispute lifecycle supports scheduled hearings, evidence-backed operational decisions, controlled reopening, and appeal records with explicit state transitions.
- Public parcel projection remains data-minimized and does not expose parties or ownership interests.
- Audit events are recorded for party creation, parcel interest claim creation, review request, approval, rejection, restriction application, and release request/decision.

## Legal Boundary

The current slice records operational party and claim information only. A `VERIFIED` ownership-interest review means a configured officer has reviewed linked evidence inside the system; it does not create legal title, does not certify ownership, and does not expose protected party details publicly. Restrictions/cautions are operational controls and evidence records, not court judgments generated by the platform. Adjudication, official registration, mortgages, leases, inheritance workflows, and ownership transfer remain future controlled workflows.

## Remaining Work

- Court-order integration, formal authority adapters, and finer appeal adjudication roles.
- Conflict handling for competing claims.
- Data-correction and appeal paths.
- Finer ABAC around party and right visibility.
